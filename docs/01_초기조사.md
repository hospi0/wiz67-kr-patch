  - 조각: [u8 바이트수+1][u8 글자(바이트)수] + 비트열(MSB 먼저).
  - ★리틀 엔디언(DOS/PSX 계보). 영문 패치가 트리 파일을 교체했으므로 → **트리를 새로 만들어 새 바이트 값을 넣을 수 있음**(⏳우리 손으로 실기 확인 필요).
